## 验证前置准备

1. **硬件外设**：
   - iPhone 15（或支持 iOS 17+ 的真机设备）；
   - Insta360 全景相机（X3 / X4 / X5，已开启 Wi-Fi 热点）；
   - 支持空间音频的 AirPods 耳机（已蓝牙配对并佩戴好）。
2. **网络配置**：
   - iPhone 连入 Insta360 相机 Wi-Fi；
   - 首次启动允许系统“本地网络”权限（`NSLocalNetworkUsageDescription`）。

## 快速验证场景 (Validation Scenarios)

### 场景 1：全屏纯净 UI 与无障碍读屏审查 (UI & Accessibility)

- **执行操作**：
  1. 启动 WalkMate 应用；
  2. 观察主屏幕视觉呈现与读屏焦点。
- **预期结果**：
  - [x] 画面上没有任何传感器遥测卡片（`SensorTelemetryCard`）或阻挡文字；
  - [x] 视频渲染区域铺满整个主屏幕背景；
  - [x] 屏幕左下角显示“连接全景相机”按钮，右下角显示“开始感知”按钮（呈半透明禁用状态）；
  - [x] 开启 VoiceOver，轻触两按钮均能读出清晰语义标签，触控靶心均 $\ge 48\text{pt}$。

---

### 场景 2：相机连接与全屏推流呈现 (Camera Streaming)

- **执行操作**：
  1. 点击左下角【连接全景相机】按钮；
  2. 观察连接过程与视频流呈现。
- **预期结果**：
  - [x] 按钮文案变为“正在连接中...”（琥珀橙色），系统发出 VoiceOver 连接提示；
  - [x] 2 秒内建立连接，全屏背景开始流畅呈现 360° 实时全景画面（$\ge 15\text{ FPS}$）；
  - [x] 左下角按钮标题切换为“断开相机”（沉稳红色）；
  - [x] 右下角【开始感知】按钮被激活，颜色变为标准无障碍高对比度绿色。

---

### 场景 3：感知与空间音频独立启停验证 (Perception Lifecycle)

- **执行操作**：
  1. 在相机连接状态下，点击右下角【开始感知】按钮；
  2. 戴着耳机静听音频输出，观察画面是否持续推流；
  3. 再次点击右下角【停止感知】按钮。
- **预期结果**：
  - [x] 点击【开始感知】后，按钮变为“停止感知”（红色），耳机中传出正前方的领路脚步声（1.1s 自然步频）；
  - [x] 点击【停止感知】后，按钮复原为“开始感知”，耳机中脚步声与警示音在 50ms 内完全静音；
  - [x] 停止感知期间，全屏视频预览依然流畅播放，零卡顿。

---

### 场景 4：前向 130° 扇区与 1 米近身避障验证 (Obstacle Sector & 1m Alert)

- **测试环境构建**：
  - 在使用者正前方 0.8 米处放置一个箱子；
  - 在使用者身后 0.8 米处放置一把椅子。
- **执行操作**：
  1. 点击【开始感知】；
  2. 保持面朝前方，聆听耳机反馈；
  3. 将身体向右转身 90 度（使箱子脱离前方 $130^\circ$ 扇区进入身侧）。
- **预期结果**：
  - [x] **背后静音**：身后的椅子虽然距离 $< 1.0\text{m}$，但绝对不发声，零误报；
  - [x] **前方近身双音报警**：前方 0.8 米的箱子触发左/右声道准确的 2 声金属撞击音，随后自动静音；期间脚步声音量被压低至 30%；
  - [x] **转身脱离扇区**：转身后箱子移至身侧外（偏角 $> 65^\circ$），金属撞击音不再触发，避障通道保持静音。

---

### 场景 5：首航路点领路验证 (First Waypoint Guidance)

- **执行操作**：
  1. 在开阔走廊中面对通道直行；
  2. 观察耳机中脚步声的声相与方位。
- **预期结果**：
  - [x] 领路脚步声稳定在正前方偏角，以 1.1s 节奏引导测试者前行；
  - [x] 走向通道尽头完全受阻时，航路点为空，脚步声自动安静。
